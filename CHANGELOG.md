## [Unreleased]

### Security
- **Single trusted address header (2026-10-08):** with `TRUST_PROXY_HEADERS=true` the server reads the client IP from `TRUSTED_IP_HEADER` only (default `x-forwarded-for`, first hop); `cf-connecting-ip` and `x-real-ip` are no longer honoured by default, and `Caddyfile.prod` strips them before proxying, so a client cannot choose its rate-limit, lockout, signup-cap, or session bucket. The default JWT secret is refused whenever proxy headers are trusted, not only in production.
- **Worker sanitizer (2026-10-08):** decoded character references are re-escaped on output, so `&lt;img onerror=...&gt;` inside an EPUB stays inert text in `chapters.html_content`.
- **Unpublished books stay hidden (2026-10-08):** chapter reads and insight lookups (by number or chapter UUID) answer 404 for draft and archived books, matching the catalog and offline bundle.
- **SMTP via `lettre` (2026-10-08):** STARTTLS (`SMTP_SECURITY=starttls`, default) with authentication replaces the hand-rolled cleartext client; `none` keeps Mailpit working locally. An unreachable relay still fails signup closed with 502. Gemini requests send the API key in `x-goog-api-key` instead of the URL, so request errors no longer log it; connection strings are logged as `scheme://host:port` and recipient addresses are masked.
- **Smaller surface (2026-10-08):** Swagger UI and the OpenAPI JSON are not mounted in production and have no edge route; `/health` answers 503 `degraded` when the process has no database connection and `/api/v1/health` no longer publishes the port; `Cache-Control: no-store` on `/api/v1/auth/*` and on every response to a bearer request; validation failures report field names without echoing the submitted value; search queries are capped at 200 characters and catalog filters at their column widths.
- **Session hygiene (2026-10-08):** logout without an `Authorization` header blacklists the access token recorded on the session; the heartbeat gate is one atomic `SET NX EX`; a repeated single quote save returns the existing row with 200 instead of a duplicate; `PATCH /admin/books/{id}` to `processing` is a 409 (the status is a job phase, never stored on a book) and the patched row is loaded by id.

### Added
- **Reader as an open book (2026-10-08):** the reader is a paper frame on a desk with running heads, folios, a spine shadow on two-column spreads, a folded corner cue, and edge arrows on wide screens. Pages turn like paper: the leaving page is rebuilt as a few strips hinged on the spine (eight on a spread, six on a single page), each a flat quad whose rotation lags its neighbour so the sheet bends, driven by a damped spring from the finger (drag anywhere on touch screens, from the page edges with a mouse) or from a tap, arrow key, Space, or PageDown. Each strip holds a clone that reproduces exactly one column, so a turn costs a page of layout rather than a chapter. A release past the middle or a flick completes the turn, an early release falls back, the last page resists, and the book closes on a finale card (owl plate) with the next steps. Center taps dim the bars, Home and End jump, a light haptic marks a landing on touch screens, and `prefers-reduced-motion` keeps the crossfade. The chapter title in the bar links to the chapter list (`/book/{id}#daftar-bab`).
- **Home catalog preview (2026-10-08):** the home page shows two rows of covers (2x2 on phones, 2x3 on tablets, 2x4 on desktops, 2x5 on wide screens) and a "see the whole catalog" button; searching or filtering shows everything with paging.
- **Idle illustrations placed (2026-10-08):** the clothesline plate marks an empty manuscript list and an empty failed-job queue on the curator desk, the pigeonholes plate a signed-in shelf with nothing saved yet, the rocket plate the 404 page, and the owl plate the reader finale.
- **Navigation markers (2026-10-08):** header and tab bar derive `aria-current` from the hash and the search query (Cara kerja, Cari, Profil light up), the active header link carries a terracotta dot, "Cara kerja" shows a down arrow, the header reads "Rak saya", a simplified seven-stroke brand mark replaces the filtered illustration in the header and as favicon, and a first visit follows the system color scheme (theme-color follows the shell).
- **Cover art without broken glyphs (2026-10-08):** covers render as CSS backgrounds resolved through `GET /api/v1/covers/{file}`; a missing image leaves the typographic plate visible.

- **Cover delivery (2026-10-08):** `GET /api/v1/covers/{file}` streams a cover from the covers bucket (`cover_url` keeps the stored key `covers/<book uuid>.<ext>`) with `Cache-Control: public, max-age=31536000, immutable`, 404 for unknown or malformed names, covered by the public read limiter.
- **Curator desk (2026-10-08, Task 15):** `/admin` becomes three panels: Manuscripts (every status with chapter and chunk counts, status filters, archive with a two-tap confirm, upload with the live job card), Queue (dead-letter entries with one-click replay), Retention (drop-off funnel per published book as bar rows). New endpoints `GET /api/v1/admin/books`, `PATCH /api/v1/admin/books/{id}` (the domain lifecycle refuses illegal steps with 409), `GET /api/v1/admin/dlq`, `POST /api/v1/admin/dlq/{id}/replay` (re-queues under the original job id, idempotent). Gallery story `curator-desk` drives the component test against mocked endpoints.
- **Worker resilience and recap context (2026-10-08, Task 16):** Gemini calls retry transient failures with quadratic backoff (1 s, 4 s, 9 s, jitter), honour `Retry-After`, and never log the key; the spoiler-free recap for chapter n is built from the key concepts of chapters 1..n-1 plus the current text within the prompt budget. Six new unit tests.
- **Per-device sessions (2026-10-08, Task 17):** every refresh token carries a session record (browser and platform from the User-Agent, coarse IP prefix, last access `jti`); `GET /api/v1/me/sessions` lists devices with the caller flagged, `DELETE /api/v1/me/sessions/{id}` drops one device (its last access token is blacklisted), `POST /auth/revoke-all?keep_current=true` signs out every other device without the global stamp. The shelf shows the device list with per-row sign-out.
- **Guest quotes and batch save (2026-10-08, Task 14):** guests keep quotes on the device (`local_quotes` store, IndexedDB v3, keyed by book, chapter, and text) and see them on the shelf; `POST /api/v1/quotes/save-batch` saves up to fifty quotes in one transaction with per-item outcomes (`saved`, `duplicate`, `rejected`); the sign-in sheet merges local quotes after guest progress and forgets every quote the server answered for.
- **Dev seed and test isolation (2026-10-08, Task 13):** `TestHarness` tracks seeded users, emails, books, and tags and every test ends with `harness.cleanup()`, so both server suites leave row counts unchanged; `make seed-dev` installs four CC0 works with fixed ids; the janitor sweeps seed survivors by test-only markers and orphan tags; the web suite pins the seed book instead of a title substring.

## [0.2.1] — 2026-09-26

### Added
- **Milestone 01 (Infrastructure & Entities):** Strongly-typed modular configuration system (`ServerConfig`, `DatabaseConfig`, `RedisConfig`, `AuthConfig`, `StorageConfig`, `EmailConfig`, `AiConfig`) loaded via `dotenvy`; dynamic SeaORM and Redis connection pools; 13 SeaORM entity models with `postgres-vector` and `PgVector` 768-dim support.
- **Milestone 02 (Authentication & Guest Reconciliation):** Complete authentication lifecycle (`/api/v1/auth/signup`, `verify-otp`, `login`, `refresh`, `logout`, `/api/v1/me`); Argon2id password hashing; Redis OTP with SHA-256 and 3-attempt limit; single-use refresh token rotation; async SMTP delivery via Mailpit; guest progress reconciliation (`/api/v1/progress/merge`) with SQL upsert and `GREATEST` progress resolution; RBAC middleware (`require_admin`).
- **Milestone 03 (Catalog Backend & Reader API):** Public catalog with cursor-based pagination and multi-filter criteria (`/api/v1/books`); typo-tolerant search (<3ms via `pg_trgm` and `word_similarity`); chapter delivery and offline reading bundles (`/api/v1/books/{id}/offline-bundle`); EPUB CFI reading progress synchronization (`/api/v1/progress/{book_id}`) and active position retrieval; daily streak gamification with heartbeat logging (`/api/v1/activity/heartbeat`); and badges system (`/api/v1/badges`, `/api/v1/me/badges`).
- **Database Index Optimization (Migration 07):** Added dedicated B-tree indexes for all Foreign Key columns to eliminate sequential scans during cascading deletes; consolidated unique indexes; and added `idx_books_published_year_id` on `books (publication_year DESC NULLS LAST, id ASC) WHERE status = 'published'` to enable zero-sort catalog pagination.
- **Automated Testing Modules:** Expanded test suite to 67 automated tests covering database integrity (`database_test.rs`), load and stress concurrency (`load_stress_test.rs`), API boundary and error envelope contracts (`api_boundary_test.rs`), and OWASP ASVS compliance (`security_owasp_test.rs`).
- **Edge Transport Architecture:** Adopted Caddy Reverse Proxy for HTTP/3 (QUIC over UDP 443) edge termination with automatic TLS and HTTP/2 over TCP fallback; preserved stateless TCP Axum backend on port 8080 (ADR-17).

### Changed
- **Redis Connection Optimization:** Pre-initialized multiplexed Tokio Redis connection in `AppState` (`state.get_redis_conn().await`), eliminating socket recreation overhead across requests.
- **Argon2id Thread Offloading:** Offloaded CPU-intensive password hashing to Tokio blocking thread pool (`tokio::task::spawn_blocking`) with calibrated parameters (19MB, 2 iterations, 1 lane) and optimized dev compilation flags (`opt-level = 3`), reducing login p95 latency from >600ms to 52ms.
- **README Redesign:** Rewrote [README.md](README.md) to provide an accessible, welcoming overview of Project Baca's literary vision, problem statement, reader features, and architecture for a general audience.

### Security
- **OWASP ASVS Hardening:** Injected mandatory global security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Strict-Transport-Security`, `Alt-Svc`); sanitized internal database errors (CWE-209); implemented IP spoofing defense prioritizing Cloudflare `CF-Connecting-IP`; added standard RFC rate-limit headers (`X-RateLimit-*`, `Retry-After`).
- **Account Abuse Controls:** 60-second OTP email cooldown; 15-minute brute-force lockout after 5 failed login attempts; JWT `jti` blacklisting on logout; multi-session revocation (`/api/v1/auth/revoke-all`); and constant-time dummy password verification preventing user email timing enumeration.
